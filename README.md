# PetChef — навигация по каталогу

Скрипт для каталога petchef.me (Tilda): переключатель «Для собак / Для кошек», табы размера и возраста, карточки «Особенности питания».

Скрипт читает адрес страницы, находит его в таблицах адресов, подсвечивает активные табы и проставляет ссылки остальным. На тематических страницах и страницах пород табы размера и возраста не выводятся: там фильтрует сама Tilda.

## Подключение в Tilda
1. **Настройки сайта → Ещё → HTML-код для вставки внутрь HEAD**:
   ```html
   <script src="https://cdn.jsdelivr.net/gh/mirowdav/petchef@main/catnav.js" defer></script>
   ```
2. На каждой странице каталога — блок **T123** над блоком каталога:
   ```html
   <div id="pc-catnav"></div>
   ```

jsDelivr кэширует `@main` до 12 часов. Чтобы изменения применились сразу, сбросьте кэш: https://purge.jsdelivr.net/gh/mirowdav/petchef@main/catnav.js

## Как добавить страницу
Создать страницу в Tilda и вписать её адрес в таблицы в `catnav.js`:
- `GRID` — страницы каталога (животное → размер → возраст);
- `THEMES` — тематические страницы (пара собаки/кошки);
- `BREEDS` — страницы пород.

Адреса с пометкой `// НОВАЯ` на сайте ещё не созданы.

## Родной фильтр Tilda
`TILDA_FILTER_SELECTOR` (по умолчанию `.t-store__filter`) — фильтр каталога Tilda (тип рациона, вкус) переносится внутрь панели. `null` — оставить фильтр на месте.
